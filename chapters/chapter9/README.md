# catstore

Example code for The Aurelia 2 Book.

## Start Dev Server

    npm start

Vite serves the app at http://localhost:3000.

## Build

    npm run build

The production bundle is written to the `dist` folder.

## Unit Tests

    npm test

Run tests in watch mode:

    npm run test:watch

## Playwright E2E Test

Install browser binaries if needed:

    npx playwright install

Run e2e tests with:

    npm run test:e2e

The Playwright config starts the Vite dev server automatically.
